THE BOOK SELLER - website files

Files:
  index.html   the shop customers see
  admin.html   your admin page (add/edit/delete books)
  books.json   your books and shop settings
  style.css    the design

Go live (free, example: Netlify):
  1. Go to app.netlify.com/drop
  2. Drag this whole folder onto the page.
  3. Open your shop link. Admin is at your-link/admin.html

Update books:
  1. Open your-link/admin.html
  2. Add or edit books, then tap "Download books.json"
  3. Upload the new books.json to your host (on Netlify drop, drag the folder again
     with the new books.json inside) to replace the old one.

Before you start: open books.json or admin.html and set your WhatsApp number
(country code first, e.g. 919876543210), shop name and tagline.
